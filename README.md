Welcome to aweb!

with aweb you can simply find out the IP-Adresses of Websites!

You just nned to enter the Domainname and you get the Ip-Adress of it.

if you need help installing it:
step one clone it:
git clone https://github.com/AbdussamedRoot/aweb_ipgrabber

step two change the directory:
cd aweb_ipgrabber

step 3 start it:
python3 main.py

and boom you can use it and find out ip adresses of domains!

Thanks for using aweb :-)
